# 明路 · SEN 学习导航器

一个面向教师的交互原型：把同一份练习转换成更容易理解的呈现方式，而不是降低题目难度或直接提供答案。

[公开体验](https://biumyang.github.io/sen-learning-navigator/)

![明路产品预览](public/og.png)

## 为什么做这个原型

部分 SEN 学生并非缺乏解题能力，而是容易被长指示、密集版面或多步骤任务卡住。教师若要为每名学生重新排版教材，也会产生大量重复工作。

这个原型验证一个具体假设：**教师能否在不改变学习目标的前提下，用几次点击生成更适合学生阅读的版本。**

## 可以体验什么

- 开关语音朗读、分步显示、专注模式和关键词提示
- 在三份预设数学练习之间切换
- 逐步查看题目中的重要资料
- 使用浏览器中文语音朗读当前内容
- 模拟教师确认，以及复制学生练习链接
- 在桌面、平板和手机尺寸下使用

## 原型边界

- 没有接入 AI、OCR、学生账号或学校系统
- 不会上传、保存或分析学生资料
- 使用预设教材，避免假装已经具备自动理解任意题目的能力
- 不提供答案，也不用于诊断学生是否有 SEN

下一步最值得验证的不是增加功能，而是找 SENCO 和前线教师测试：生成流程是否比重新制作练习更省时间，以及分步版本是否确实保留原来的学习目标。

## 本地运行

需要 Node.js 22.13 或以上版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。

## 验证

```bash
pnpm lint
pnpm test
```

## 技术

React 19、TypeScript、Vinext、Vite、Cloudflare Workers。
