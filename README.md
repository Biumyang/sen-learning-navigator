# 明路 · SEN 學習導航器

一個面向教師的互動原型：把同一份練習轉換成更容易理解的呈現方式，而不是降低題目難度或直接提供答案。

[公開體驗](https://biumyang.github.io/sen-learning-navigator/)

![明路產品預覽](public/og.png)

## 為甚麼做這個原型

部分 SEN 學生並非缺乏解題能力，而是容易被長指示、密集版面或多步驟任務卡住。教師若要為每名學生重新排版教材，也會產生大量重複工作。

這個原型驗證一個具體假設：**教師能否在不改變學習目標的前提下，用幾次點擊生成更適合學生閱讀的版本。**

## 可以體驗甚麼

- 開關語音朗讀、分步顯示、專注模式和關鍵詞提示
- 在三份預設數學練習之間切換
- 讓學生從題目中選出每一步所需的數字，答對後才進入下一步
- 選錯時提供低壓力提示，而不直接顯示答案
- 使用瀏覽器廣東話語音朗讀目前內容
- 模擬教師確認，以及複製學生練習連結
- 在桌面、平板和手機尺寸下使用

## 原型邊界

- 沒有接入 AI、OCR、學生帳戶或學校系統
- 不會上傳、儲存或分析學生資料
- 使用預設教材，避免假裝已經具備自動理解任意題目的能力
- 不提供最終答案，也不用於診斷學生是否有 SEN

下一步最值得驗證的不是增加功能，而是找 SENCO 和前線教師測試：生成流程是否比重新製作練習更省時間，以及分步版本是否確實保留原來的學習目標。

## 本機運行

需要 Node.js 22.13 或以上版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

開啟 `http://localhost:3000`。

## 驗證

```bash
pnpm lint
pnpm test
```

## 技術

React 19、TypeScript、Vinext、Vite、Cloudflare Workers。
